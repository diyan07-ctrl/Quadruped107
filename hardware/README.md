# Hardware assets

- [cad](cad/): original Fusion 360 F3Z archive and STEP assembly.
- [stl](stl/): 24 original part files plus the supplied STL_Final.zip.
- [calibration](calibration/): original servo table and controller key-binding spreadsheets.

Original geometry and calibration values are preserved byte-for-byte. Some mirrored/named assembly parts have identical mesh contents; retain filenames so assembly references remain understandable. The ZIP is a preserved supplied distribution, not a second active source tree.

Images and animation remain in [docs](../docs/HARDWARE.md). The original electrical image and UNO Q board mounts are historical; use the [proposed Pi/Uno wiring](../docs/WIRING.md). Spreadsheets and inherited pulse targets require physical verification before use.
