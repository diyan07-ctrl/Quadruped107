# Legacy UNO Q tools

These calibration and deprecated control applications depend on Arduino App Lab / UNO Q Bridge. They are retained as reference and are **not part of the Raspberry Pi 4 + Uno R3 runtime**.

Use [Quadruped107 Connect](../Quadruped107-connect/README.md) and its `/api/servo` endpoint for the active Pi / Uno calibration path. Do not flash these legacy sketches to the Uno R3.
